# Package index

## All functions

- [`clusterRepLasso()`](https://gregfaletto.github.io/cssr-project/reference/clusterRepLasso.md)
  : Select features via the cluster representative lasso (Bühlmann et.
  al. 2013)
- [`css()`](https://gregfaletto.github.io/cssr-project/reference/css.md)
  : Cluster Stability Selection
- [`cssLasso()`](https://gregfaletto.github.io/cssr-project/reference/cssLasso.md)
  : Provided fitfun implementing the lasso
- [`cssPredict()`](https://gregfaletto.github.io/cssr-project/reference/cssPredict.md)
  : Wrapper function to generate predictions from cluster stability
  selected model in one step
- [`cssSelect()`](https://gregfaletto.github.io/cssr-project/reference/cssSelect.md)
  : Obtain a selected set of clusters and features using cluster
  stability selection
- [`genClusteredData()`](https://gregfaletto.github.io/cssr-project/reference/genClusteredData.md)
  : Generate randomly sampled data including noisy observations of
  latent variables
- [`genClusteredDataWeighted()`](https://gregfaletto.github.io/cssr-project/reference/genClusteredDataWeighted.md)
  : Generate randomly sampled data including noisy observations of
  latent variables, where proxies differ in their relevance (noise
  level)
- [`genClusteredDataWeightedRandom()`](https://gregfaletto.github.io/cssr-project/reference/genClusteredDataWeightedRandom.md)
  : Generate randomly sampled data including noisy observations of
  latent variables, where proxies differ in their relevance (noise
  level)
- [`getCssDesign()`](https://gregfaletto.github.io/cssr-project/reference/getCssDesign.md)
  : Obtain a design matrix of cluster representatives
- [`getCssPreds()`](https://gregfaletto.github.io/cssr-project/reference/getCssPreds.md)
  : Fit model and generate predictions from new data
- [`getCssSelections()`](https://gregfaletto.github.io/cssr-project/reference/getCssSelections.md)
  : Obtain a selected set of clusters and features
- [`getLassoLambda()`](https://gregfaletto.github.io/cssr-project/reference/getLassoLambda.md)
  : Get lambda value for lasso
- [`getModelSize()`](https://gregfaletto.github.io/cssr-project/reference/getModelSize.md)
  : Automated estimation of model size
- [`getNoiseVar()`](https://gregfaletto.github.io/cssr-project/reference/getNoiseVar.md)
  : Get variance of noise to add to Z in order to yield proxies X with
  desired correlations with Z
- [`plot(`*`<cssr>`*`)`](https://gregfaletto.github.io/cssr-project/reference/plot.cssr.md)
  : Plot cluster (or feature) selection proportions from cluster
  stability selection
- [`print(`*`<cssr>`*`)`](https://gregfaletto.github.io/cssr-project/reference/print.cssr.md)
  : Print cluster stability selection output
- [`printCssDf()`](https://gregfaletto.github.io/cssr-project/reference/printCssDf.md)
  : Prepares a data.frame summarizing cluster stability selection output
  to print
- [`protolasso()`](https://gregfaletto.github.io/cssr-project/reference/protolasso.md)
  : Select features via the protolasso (Reid and Tibshirani 2016)
- [`selected()`](https://gregfaletto.github.io/cssr-project/reference/selected.md)
  : Extract the selected clusters or features from cluster stability
  selection
- [`print(`*`<summary.cssr>`*`)`](https://gregfaletto.github.io/cssr-project/reference/summary.cssr.md)
  [`summary(`*`<cssr>`*`)`](https://gregfaletto.github.io/cssr-project/reference/summary.cssr.md)
  : Summarize cluster stability selection output
